## Sample Prompts

These are example prompts used with Claude or other AI assistants to generate various components of this heritage website. Each demonstrates effective prompting techniques for different content types.

### Planning and Structure

**[Personas](./personas.md)** - Prompt for generating detailed user personas for a heritage website. Creates profiles of different visitor types (genealogists, educators, students, tourists) with their goals, questions, and usage patterns. Essential for understanding your audience and prioritizing content.

**[Site Layout](./site-layout.md)** - Prompt for generating an information architecture and navigation structure based on persona analysis. Organizes content to serve the most frequent visitors while remaining accessible to all users.

### Content Generation

**[Chapter Content](./chapter-content.md)** - Prompt for generating comprehensive chapter text at appropriate reading levels (10th grade). Requests tables, lists, images, diagrams, and glossary links throughout the content.

**[Timeline Chapter Text](./timeline-chapter-text.md)** - Specialized prompt for generating a timeline-focused chapter with historical events organized chronologically. Uses a timeline.json file as source material.

**[FAQs](./faqs.md)** - Prompt for generating 100 frequently asked questions organized by category. Targets specific reading level and provides structured question-answer format with level-4 headers.

**[Quiz](./quiz.md)** - Prompt for generating interactive quizzes to test comprehension of historical content. (Note: This file appears to be a stub - may need completion)

### Interactive Elements

**[Migration Map](./migration.md)** - Prompt for creating an interactive Leaflet.js map showing migration patterns from Scotland through Ireland to North America. Includes animated routes with "Show Migration" button and color-coded markers.

**[Ulster Plantation Map](./ulster-plantation-map.md)** - Prompt for generating a focused map of Northern Ireland counties using Leaflet JavaScript library. Highlights specific Ulster counties with detailed borders.

**[Graphic Novel Generation](./graphic-novel-generation.md)** - Detailed prompt for creating a 14-panel graphic novel explaining the Ulster Plantation and Scotch-Irish migration. Includes specific panel descriptions, image generation instructions, and narrative text format.
